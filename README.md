# Handwritten-Digit-Recognition-Using-Artificial-Neural-Networks


# Problem Statement

* Handwritten digits vary greatly in shape and style, making manual recognition difficult and error-prone. An automated system is required to accurately identify handwritten digits from images. The objective of this project is to develop an Artificial Neural Network (ANN) using the MNIST dataset to classify handwritten digits from 0 to 9 efficiently and accurately.

# Objective

* To build an ANN model for handwritten digit recognition

* To understand image preprocessing and normalization

* To evaluate model performance using standard classification metrics

# Dataset

* Dataset Name: MNIST Handwritten Digits

* Source: tensorflow.keras.datasets.mnist

* Training Samples: 60,000

* Testing Samples: 10,000

* Image Size: 28 × 28 pixels

* Classes: Digits 0–9

# Model Architecture

* Input Layer: 28 × 28 image flattened to 784 neurons

* Hidden Layer 1: 128 neurons (ReLU)

* Hidden Layer 2: 64 neurons (ReLU)

* Output Layer: 10 neurons (Softmax)

#  Results

* The ANN achieved high accuracy on the test dataset.

* Most handwritten digits were classified correctly.

* The classification report shows strong precision, recall, and F1-scores across classes.

* The model generalizes well to unseen data.

# Visualization Explanation

* Accuracy Curve: Shows improvement of training and validation accuracy over epochs.

* Loss Curve: Shows reduction in training and validation loss, indicating effective learning.

* These visualizations help in understanding model learning behavior and detecting overfitting.

# Conclusion

* An Artificial Neural Network was successfully implemented to classify handwritten digits using the MNIST dataset. The project demonstrates effective preprocessing, model training, evaluation, and visualization, making it a strong beginner-friendly deep learning project.
